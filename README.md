# Fitness Website

A modern fitness website showcasing workout routines, trainers, and healthy lifestyle tips.

## Live Demo
[GitHub Pages Demo](https://showrav-sarkar555.github.io/fitness-website/)

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Features
- Responsive design
- Trainer profiles
- Exercise showcase
- Contact information

## How to Run Locally
1. Clone the repository:
   ```sh
   git clone https://github.com/showrav-sarkar555/fitness-website.git
   ```
2. Open `index.html` in your browser.

## Folder Structure
- `images/` - Exercise and trainer images
- `fitness.css` - Main stylesheet
- `index.html` - Main HTML file
